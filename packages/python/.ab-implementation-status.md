### Phase 2 — Completed 2026-08-16
- Added `_run_pharos_cli(*args) -> str` helper after `_get_pharos_cli()` (line ~840).
  Uses `asyncio.create_subprocess_exec` with 30s timeout. Returns JSON with
  `status` (ok/error), `stdout`, `stderr`, `returncode`. On timeout: includes
  `"timeout": True` flag. On FileNotFoundError: includes `"hint"` key.
- `pharos_info` and `pharos_publish` added inside the `if not MCP_APPS_MODE:` block
  (CLI-mode only). `pharos_publish` takes optional `server_card_path` — when empty,
  runs `pharos publish` without a directory argument.
- 22 non-A/B tools added after `pharos_daemon_status`, before MCP Resources section.
  All registered unconditionally (available in both CLI and Apps modes).
- `pharos_config` has special logic: when `value` is empty, runs `pharos config <key>`
  (get mode); when value is provided, runs `pharos config <key> <value>` (set mode).
- Skipped interactive CLI commands: `login` (browser OAuth), `init` (scaffolding),
  `package` (sub-command of publish), `republish` (rarely needed).
- All 89 tests pass: `python -m pytest tests/unit/test_mcp_server.py -v`
